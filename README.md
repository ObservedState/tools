# Tools
A collection of Apps, Scripts, shell setups and their documentation.  Essentially, things that I have created or adapted over time in my work. Where I feel strongly enough, I leave review thoughts.


## Shells
I have recently started working with [Starship](https://starship.rs/) which is a prompt tooling replacement that works across multiple OSes and Shells, even Powershell.  The setup .toml files in /starship should be moved to whatever directory you have set as your config directory in Windows.



## Fonts
[Nerd Fonts](https://www.nerdfonts.com/font-downloads) are used for terminal fonts that work with things like Oh-My-ZSH and Starship, where glyphs are used. This is a super-set of FontAwesome, Powerline fonts, Material Design, Codicons and several more, ending up above the 10,000 icons mark at the time of this writing.  In your terminal.  The one I settled on, across the board, was [FiraCode Nerd Font](https://www.programmingfonts.org/#firacode) but other popular choices are [InconsolataGo](https://www.programmingfonts.org/#inconsolata-go) and [Cascadia Code](https://www.programmingfonts.org/#cascadia-code).

NOTE: In VSCode, make sure that you edit **both**  the VSCode Editor Font Face setting and the terminal.integrated.fontFamily setting, and that you have ligatures enabled in both places.
